# Integração do portal premium

O ZIP `NEONPLAY_PORTAL_PREMIUM` foi integrado à homepage existente por comparação com a branch `main`. A proposta visual, o CSS e os 127 cartões GamePix foram preservados. Também foram mantidos o domínio canônico `zapgame.com.br`, a seção de jogos instalados e o script que carrega o catálogo de jogos locais e multiplayer a partir de `games-imported.json`.

Os arquivos README e REDESIGN-NOTES do pacote foram guardados nesta pasta; o README principal do repositório não foi substituído.
